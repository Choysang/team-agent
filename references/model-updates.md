# 模型更新与卡片

[返回主流程](../SKILL.md) · [能力与宿主分流](harness-matrix.md)

每次调用通过当前宿主适配器检查目录，不设后台定时器。比较模型标识与真实档位，顺序和时间戳不构成变化；读取失败不当作下架。外部发现与当前可调用模型分开，未知档位不补造。

出现待处理变化时展示全配置，再让用户选择修改角色或本次不更新。用户在当前任务内完成所有选择：模型 → 该模型档位 → 是否添加备选 → 每个备选模型/档位。独立问题可批量，有依赖的卡片等上一步回答后生成，不要求另开会话。

宿主有原生卡片时使用原生卡片；否则展示编号选项。备选至少区分“添加备选”“本次不添加”“此角色以后不再询问”。只有最后一项保存长期免打扰偏好；空备选不能代替该回答。用户明确要求修改备选时可重新进入设置。

保存未选角色原值，重新校验并应用，再执行受影响角色的本次实际调用测试。用户完成或明确不更新后，仅确认该次变化指纹；具体保存和确认命令由宿主适配器提供。没有对应持久化实现时，不声称跨会话已记住选择。

目录尚未刷新或当前接口未提供候选时，不把外部发现条目冒充可调用模型。已处理更新不反复询问。
