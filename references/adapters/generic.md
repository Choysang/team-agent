# 通用适配与其他宿主

[返回能力与宿主分流](../harness-matrix.md) · [返回主流程](../../SKILL.md)

用于没有专用适配卡的宿主，或宿主版本已变化、适配卡与现场不符时。

## 现场判定四个问题

1. **调用参数**：看你自己的子代理派发工具定义。参数中有模型、强度类字段吗？取值是什么？
2. **角色文件**：宿主是否支持自定义子代理文件？查官方文档（用搜索工具）和本机配置目录，确认位置与 `model`、强度类字段。
3. **设置或环境变量**：是否有按代理名覆盖模型的设置键，或会压过一切的环境变量？
4. **证据**：本地有没有记录子代理实际模型的会话日志？

按答案归类，选其中最直接的一种作为该宿主的唯一主方案（优先B或C这类宿主自己保存的配置，其次A）：

| 类型 | 条件 | 做法 |
|---|---|---|
| A | 有调用参数 | 路由说明写明每个职能传什么；升级阶梯按此显式传 |
| B | 有角色文件模型字段 | 生成 `team-<职能>` 文件，带生成标记 |
| C | 只有全局或按名称的设置 | 只改自己负责的键，保留其余内容 |
| D | 都没有 | 如实告诉用户该宿主不支持给子代理单独指定模型，只能切换主会话模型；不写任何文件 |

记录核对日期与依据，作为该宿主新适配卡的草稿交给用户。

## 已知宿主现状（2026-10-27）

| 宿主 | 现状 | 结论 |
|---|---|---|
| Kimi Code CLI | 代理文件位于 `$KIMI_CODE_HOME/agents/`、`~/.agents/agents/`、项目 `.kimi-code/agents/`、`.agents/agents/`；文档明确忽略其他工具的 `model` 字段；内置coder/explore/plan | 类型D：子代理不能单独设模型 |
| Kiro | 自定义代理放在 `.kiro/agents/`，可作为子代理调用；子代理文档未说明模型字段 | 按四个问题现场判定 |
| Trae | 未找到公开的子代理模型配置文档；本机 `~/.trae-cn` 只有插件与技能配置 | 按四个问题现场判定，多数情况为类型D |
| Windsurf、Cline、Roo Code等 | 未核对 | 按四个问题现场判定 |

来源：[Kimi Code代理与子代理](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/sub-agents.html)、[Kiro子代理](https://kiro.dev/docs/custom-agents/subagents/)。
